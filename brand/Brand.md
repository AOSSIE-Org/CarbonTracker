# CarbonTracker Brand Guidelines

## Logo

![CarbonTracker Logo](logo.svg)

The CarbonTracker logo is the primary visual identifier of the project.

## Colors

### Primary Colors

| Name                  | Hex       | Usage                                                             |
|-----------------------|-----------|-------------------------------------------------------------------|
| Primary               | `#5E6F00` | Primary accent / brand green, used for key actions and highlights |
| Main Background Color | `#FCFBF2` | Main background color                                             |
| Focused               | `#55650C` | Focus states, active elements                                     |

### Supporting Colors

| Name                  | Hex                     | Usage                                           |
|-----------------------|-------------------------|-------------------------------------------------|
| Subtitle Text         | `#464839`               | Secondary body/subtitle text                    |
| Minuscule Text        | `#777868`               | Smallest/least prominent text (captions, hints) |
| Text Dark             | `#1C1C1C`               | Primary dark text                               |
| Option Background     | `#F5F4E8`               | Background for selectable option components     |
| Selected Option       | `#9BAD50`               | Background for a selected option                |
| Selected Option Text  | `#343F00`               | Text color on a selected option                 |
| Unselected Border     | `#C7C8B5`               | Border for unselected/inactive elements         |
| Modal Background      | `#F2F0E0`               | Background for modals/dialogs                   |
| Modal Border          | `#D7D3BE`               | Border for modals/dialogs                       |
| Metrics Background    | `#9BAD50` (6% opacity)  | Background tint for metric cards/stats          |
| Olive Green           | `#93A360`               | Supporting green accent                         |
| Grey Border           | `#EDEBDA`               | General light border color                      |
| Green Icon Background | `#9BAD50` (16% opacity) | Background behind green icons                   |
| Green Icon            | `#55650C`               | Green icon color                                |
| Grey Icon Background  | `#B0A296` (16% opacity) | Background behind grey icons                    |
| Grey Icon             | `#685C52`               | Grey/neutral icon color                         |
| Green Border          | `#C7C8B5`               | Border variant used with green elements         |

## Typography

CarbonTracker uses Flutter's default typography and does not currently use a custom font.

## Icons

CarbonTracker uses Flutter's built-in Material Icons. No third-party icon library is currently used.

## Design Principles

- Clean and minimal
- Sustainability-focused
- Privacy-first
- Accessible and easy to read
